# ImageChange v3.0.0

ImageChange 3.0.0 adds a bilingual Chinese and English interface and packages the existing offline PDF-to-image workflow for public release.

## What's new

- Chinese remains the default language; English can be selected from the settings panel.
- Language changes apply immediately and preserve the file queue and conversion settings.
- The selected language is restored on the next launch.
- PDFs can be previewed and rendered by page at 96-400 DPI.
- PDF sources are always preserved.
- Invalid PDF page ranges now report an error instead of being silently clipped.

## Windows download

Download `ImageChange-3.0.0-win64.zip`, extract it, and run `ImageChange.exe`. Keep the `tools` directory beside the executable.

## Verification

Use `SHA256.txt` to verify the executable. The binary is not code-signed, so Windows may show an unknown publisher warning.
