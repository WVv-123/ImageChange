# ImageChange 3.0.0 使用说明

## 启动

1. 解压完整发布包。
2. 保持 `ImageChange.exe` 与 `tools` 文件夹位于同一目录。
3. 双击 `ImageChange.exe`。

## 切换语言

- 程序默认显示中文。
- 在右侧设置区顶部的“语言”下拉框中选择 `English`，界面会立即切换为英文。
- 文件队列和转换参数在切换语言时保持不变。
- 语言偏好会自动保存，下次启动继续使用上次选择。

## 图片转换

1. 添加图片、PDF 或文件夹。
2. 选择输出格式、尺寸、处理方式和保存位置。
3. 点击“开始转换”。

## PDF 转图像

- 支持直接选择、拖拽或从文件夹扫描 PDF。
- 可选择全部页面、仅首页或指定页码，例如 `1-3,5,8`。
- 支持 96、150、200、300 和 400 DPI。
- 多页 PDF 会按 `_p01`、`_p02` 形式输出多个图像文件。
- 原始 PDF 始终保留，即使选择“覆盖原文件”也不会删除。

## 安全说明

- 所有处理均在本机完成，不上传文件或路径。
- 覆盖图片前会要求二次确认，并提供冲突保护与失败回滚。
- 当前 EXE 未使用商业代码签名证书，Windows 可能显示“未知发布者”。
