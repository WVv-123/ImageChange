# Changelog

## 3.0.0 - 2026-10-26

- Added an in-app Chinese and English language selector.
- Kept Chinese as the default language and persisted the selected language.
- Preserved the queue and conversion settings during language changes.
- Added local PDF loading, preview, page selection, and image export.
- Added strict validation for PDF page ranges.
- Added bilingual GitHub documentation and MIT licensing.

## 2.9.0 - 2026-10-26

- Added PDFium-based offline PDF rendering.
- Added PDF DPI and page range controls.
- Preserved source PDFs in every output mode.

## 2.7.0 - 2026-08-01

- Introduced the Bright Haze interface and improved settings scrolling.
