# Contributing

1. Create a focused branch for one change.
2. Install the pinned dependencies from `requirements.txt`.
3. Add or update tests for behavior changes.
4. Run `python -m unittest discover -s tests` before opening a pull request.
5. For interface changes, verify both Chinese and English at 1180x760 and 980x650.
6. Do not commit virtual environments, build output, local settings, or test files.

Bug reports should include the ImageChange version, Windows version, input format, selected output settings, and the exact error shown by the application. Do not attach private documents unless they are safe to publish.
